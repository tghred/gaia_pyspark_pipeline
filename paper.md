# Summary
`Gaia-PySpark-Pipeline` is an open-source, lightweight Python package designed to extract and isolate open stellar clusters from the Gaia DR3 catalog. By coupling ADQL server-side spatial filtering with PySpark's distributed processing and Scikit-Learn's DBSCAN clustering, this pipeline enables resource-constrained researchers to efficiently process multi-dimensional astronomical datasets without requiring High-Performance Computing (HPC) clusters.

# Statement of Need
The Gaia DR3 dataset contains over 1.8 billion astronomical sources [@GaiaDR3]. While querying large sky areas is computationally intensive, existing pipelines often rely on heavy infrastructure or localized scripts that lack modularity and reproducibility. `Gaia-PySpark-Pipeline` bridges this gap by offering an end-to-end modular framework that executes spatial filtering via ADQL, converts raw data to optimized local Parquet stores, and uses PySpark for memory-efficient cleaning before applying DBSCAN on 5D kinematic vectors.

# Architecture & Workflow
The package consists of three main modules:
1. `fetch_data`: Asynchronously launches ADQL queries targeting astrometric parameters ($\varvarpi, pm_{ra}, pm_{dec}$).
2. `spark_cleaner`: Initializes a local `SparkSession` to handle missing/unphysical values using distributed dataframes.
3. `clustering`: Converts cleaned vectors to NumPy arrays, applies `StandardScaler`, and isolates stellar cluster members from background field stars.
